# hospital_ai

AI system for hospital workflows, built on the [Mastra](https://mastra.ai) TypeScript agent framework.

## Status

🚧 Early development — project scaffolding in progress.

## Stack

- **Mastra** — agents, tools, workflows, RAG, memory, scorers/evals
- TypeScript + Zod

## Development

The Mastra docs MCP server is configured in `.mcp.json` (`@mastra/mcp-docs-server`) for version-accurate API reference during development.

```bash
# (after scaffolding)
npm install
npx mastra dev      # Mastra Studio playground at http://localhost:4111
```
